# Data Visualization Practice (Matplotlib & Seaborn)

A comprehensive collection of Python data visualization practice notebooks built with Matplotlib and Seaborn.

## 🛠️ Libraries Used
To run this project/notebook, ensure you have the following libraries installed:
* Python 3.x
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 What's Included
* Basic line plots, scatter plots, and bar charts using Matplotlib.
* Advanced statistical visualizations using Seaborn.
* Customizing plot styles, colors, markers, and labels.
* Data cleaning and preparation for visualization.

## 🚀 How to Run
1. Clone or download this repository.
2. Open your preferred Python environment (e.g., Jupyter Notebook).
3. Run the notebook file to explore the visualizations.
